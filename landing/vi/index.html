03 — CÀI ĐẶT SERVER

Thiết lập
hệ thống nguồn.

Có 2 cách cài đặt tùy nhu cầu. Hầu hết mọi người chỉ cần Cách A là đủ. Cách B dành cho ai muốn mở khóa thêm FlyStream hoặc dùng chung cho WuPlay / Stremio.

Cách A · ~60 giây · Khuyên dùng

Không cần server — dùng trực tiếp link GitHub

7Movies và Movy chạy như tiện ích mở rộng ngay bên trong ứng dụng xem phim trên TV. Bạn không cần cài đặt hay treo máy chủ gì cả. Chỉ cần dán một đường link vào Nuvio là tự động đồng bộ lên TV.

  1. Trên điện thoại hoặc máy tính, truy cập nuvioapp.space/account → đăng nhập → chọn Plugins → Add plugin.
  2. Dán đường dẫn manifest bên dưới rồi bấm Lưu (Save). Mở TV lên kiểm tra: thấy hiện tên các nguồn phát là thành công.
  3. Trên TV, vào Settings → Content & Discovery → Plugins và gạt BẬT mục “Enable plugin providers globally” (lưu ý phải dùng bản Nuvio cài file APK ngoài, bản trên CH Play bị khóa tính năng này).
https://raw.githubusercontent.com/phuanh004/direct-streams-providers/refs/heads/main/manifest.json
Cách B · ~10 phút · Mở khóa FlyStream & tự host

Server phụ trợ — chạy server.js

Một dịch vụ Node.js siêu nhẹ chạy ở cổng 7070, không cần cài thêm thư viện rườm rà. Nó giúp cấp manifest nội bộ và xử lý cookie vượt rào cho FlyStream. Bạn có thể chạy trên Raspberry Pi, máy tính bật sẵn ở nhà hoặc đưa lên cloud.

  • Cài sẵn Node.js 18 trở lên (đã chạy tốt tới Node 26)
  • Dùng chung Wi-Fi với TV nếu chạy mạng nội bộ — nên dùng tên miền .local thay vì số IP dễ bị đổi
  • Giữ cửa sổ server chạy ngầm trong suốt lúc xem nguồn FlyStream
git clone https://github.com/phuanh004/direct-streams-providers.git
cd direct-streams-providers
npm install  # esbuild
npm run build
npm run serve  # → :7070
  1. Khởi chạy server trên Pi hoặc máy tính bằng bộ lệnh ở Cách B. Giữ terminal luôn mở (hoặc cho chạy ngầm qua pm2 / systemd).
  2. Xem tên miền .local của máy — ví dụ raspberrypi.local hoặc tên máy tính trong mạng LAN. Cách này giúp link không bao giờ bị chết khi modem đổi địa chỉ IP.
  3. Dán link manifest này vào ứng dụng xem phim. Tất cả thiết bị trong nhà dùng chung Wi-Fi đều dùng chung một link duy nhất.
http://<ten-may-chu>.local:7070/manifest.json
  1. Đưa tệp worker.js kèm cấu hình wrangler.toml trong repo lên Cloudflare Workers — chạy hoàn toàn trên đám mây mà không cần bật máy tính ở nhà.
  2. Lấy địa chỉ Workers được cấp làm đường dẫn manifest, dạng https://<ten-worker>.<tai-khoan>.workers.dev/manifest.json.
  3. Giải pháp lý tưởng nếu bạn hay mang TV Box đi xa hoặc không muốn nuôi một thiết bị chạy 24/7 tại nhà.
  1. Kết nối repo vào Vercel — hệ thống sẽ tự nhận diện server.js để chạy như một server add-on hoàn chỉnh.
  2. Ghép tên miền Vercel được cấp với đuôi /manifest.json rồi thêm vào Nuvio, WuPlay hoặc Stremio.
  3. Mỗi khi repo có bản cập nhật mới, chỉ cần bấm re-deploy trên Vercel để làm mới bộ nguồn.

Nên chạy bài kiểm tra ngoại tuyến trước (không tốn băng thông, không làm quá tải máy chủ nguồn), sau đó mới thử kết nối thực tế:

npm run test:offline  # kiểm tra nội bộ + router + flystream + movy
npm test             # kiểm tra mạng thực tế — hạn chế chạy liên tục

Nếu hệ thống khỏe mạnh, kết quả sẽ báo: Oppenheimer (872585) → 1 luồng · Breaking Bad S01E01 (1396) → 4 luồng (1080p–360p), 8 bản phụ đề.

Lưu ý quan trọng: Nguồn FlyStream sẽ không hiện phim nào nếu bạn dùng link manifest trực tiếp từ GitHub. Nó chỉ hoạt động qua Cách B vì server phụ trợ cần tự chèn địa chỉ kết nối vào tệp providers/flystream.js.
04 — CÀI TRÊN ỨNG DỤNG

Thêm nguồn vào
từng ứng dụng.

Cùng một hệ thống nguồn phim, hỗ trợ 3 nền tảng phổ biến. Sau khi xong bước server, hãy chọn ứng dụng bạn đang dùng để xem hướng dẫn.

  1. Cài bản Nuvio APK tải ngoài lên TV (bản tải trên Google Play Store đã bị gỡ bỏ phần plugin theo quy định của Google).
  2. Thêm plugin bằng điện thoại như hướng dẫn ở Cách A. Mọi thứ tự động đồng bộ sang TV trong tích tắc, đỡ tốn công bấm điều khiển gõ từng chữ.
  3. Hoặc nhập trực tiếp trên TV: vào Settings → Content & Discovery → Plugins → chọn quét mã QR bằng điện thoại, hoặc dán link vào mục “URL or short code” → + Add. Cuối cùng nhớ gạt BẬT “Enable plugin providers globally”.
  1. Bật server phụ trợ (Cách B) bằng lệnh npm run serve ở cổng :7070.
  2. Mở trang cấu hình WuPlay: trên TV vào Settings → Configuration rồi quét mã QR để mở config.wuplay.app — WuPlay lưu cấu hình trên tài khoản đám mây nên chỉ cần thêm một lần là tự đồng bộ sang mọi thiết bị khác.
  3. Dán đường dẫn manifest theo định dạng .local dưới đây.
http://<ten-may-chu>.local:7070/manifest.json
  1. Bật server phụ trợ (Cách B) chạy ở cổng :7070.
  2. Dán thẳng link manifest vào ô tìm kiếm của Stremio, hoặc mở bằng đường dẫn stremio://.
  3. Kiểm tra lại: tiện ích sẽ xuất hiện trong mục Add-ons đã cài, và khi bấm vào bất kỳ bộ phim nào bạn sẽ thấy thêm các dòng nguồn phát mới.

Ưu tiên dùng tên miền .local để Stremio luôn kết nối ổn định kể cả khi modem Wi-Fi khởi động lại và đổi IP.

05 — SỬ DỤNG HÀNG NGÀY

Thoải mái xem phim,
trên mọi màn hình.

Cài đặt chỉ tốn vài phút ban đầu, còn đây là trải nghiệm dùng hàng ngày. Chạm vào từng thiết bị để xem cách tận dụng hiệu quả nhất.

Nhịp sử dụng quen thuộc mỗi ngày

BAN NGÀY — TRÊN ĐIỆN THOẠI

Lướt tìm phim lúc rảnh

Tranh thủ giờ nghỉ lướt xem phim hay, kiểm tra trước xem nguồn nào đã có bản đẹp hay 4K. Không cần tải trước gì cả, chỉ cần lưu lại tên phim.

BUỔI TỐI — TRÊN MÀN HÌNH TV

Lên đèn và thưởng thức

Mở phim trong Nuvio trên TV. Chọn Movy 2160p cho phim điện ảnh mãn nhãn, hoặc 7Movies 1080p nếu mạng buổi tối hơi chập chờn. Phụ đề đã có sẵn trong trình phát.

TRONG LÚC XEM — MỌI MÀN HÌNH

Mẹo chọn chất lượng chuẩn

Không phải lúc nào 4K cũng tối ưu nhất: bản 1080p MP4 vào phim gần như tức thì và tua rất mượt; bản 4K HLS phát huy tối đa trên TV cắm dây LAN hoặc Wi-Fi 5GHz mạnh. Nếu một nguồn bị đứng hình, cứ thoát ra chọn nguồn khác.

ĐI DU LỊCH — TABLET / LAPTOP

Mang rạp phim theo bên mình

Cách A hoạt động ở bất cứ đâu có internet — đi công tác hay du lịch đều dùng bình thường. Riêng link LAN của Cách B chỉ dùng trong mạng nội bộ ở nhà; khi ra ngoài hãy chuyển sang Cách A hoặc bản deploy trên cloud.

Xử lý nhanh khi phim không chạy

  1. Báo lỗi 428 / bị chặn? Do bạn đang dùng bản cũ chưa có header okhttp — hãy cập nhật lại link manifest mới nhất.
  2. Lỗi 429 / không hiện danh sách nguồn? Hãy kiên nhẫn đợi khoảng 1 phút. Hệ thống tự động giãn nhịp khi máy chủ gốc quá tải — bấm thử lại liên tục càng dễ bị chặn lâu hơn.
  3. FlyStream không ra kết quả? Kiểm tra xem server phụ trợ đã bật chưa, hoặc địa chỉ IP có bị đổi không. Khởi động lại server.js và ưu tiên dùng tên miền .local.
  4. Trống trơn không thấy nguồn nào? Vào cài đặt Nuvio kiểm tra mục “Enable plugin providers globally” đã bật chưa và đảm bảo bạn đang dùng bản APK cài ngoài.

Bí quyết giúp chạy mượt trên máy yếu

Hệ thống được tinh chỉnh kỹ cho các đầu TV Box RAM 1.5–2 GB: đặt giới hạn thời gian tối đa 9 giây cho mỗi nguồn để không treo app, bộ nhớ đệm LRU/FIFO siêu nhẹ, gộp các yêu cầu trùng lặp và đọc luồng HLS một lượt duy nhất. 7Movies tự động thử lại thông minh theo Retry-After; còn Movy dò cuốn chiếu 3 server cùng lúc (ưu tiên Miami và Boise) và tạm nghỉ 30 giây nếu gặp giới hạn 429.

Thói quen bảo trì mỗi tuần: chạy git pull, gõ npm run build rồi khởi động lại server — chỉ mất chưa đầy 2 phút để toàn bộ thiết bị trong nhà luôn có nguồn phim mới nhất.

06 — HỎI ĐÁP NHANH

Giải đáp
thắc mắc thường gặp.

Tôi có phải đăng ký tài khoản hay mua API key không?

Hoàn toàn không cần tài khoản hay API key cho các nguồn phim — chỉ cần dán link manifest là dùng được 7Movies và Movy. Riêng với Nuvio, bạn chỉ dùng tài khoản Nuvio cá nhân tại nuvioapp.space để đồng bộ cài đặt lên TV cho tiện (hoặc nhập thẳng trên TV cũng được). Chỉ khi dùng thêm FlyStream mới cần bật server phụ trợ.

Tôi có bắt buộc phải tự chạy server không?

Không bắt buộc. Bạn chỉ cần server nếu muốn dùng FlyStream, WuPlay hoặc chế độ add-on trên Stremio. Nếu chỉ xem qua Nuvio với hai nguồn chủ lực là 7Movies và Movy, hãy chọn Cách A (dùng link GitHub) — mọi thứ chạy trực tiếp ngay trên TV của bạn.

Giao diện hướng dẫn này có gì đặc biệt?

Trang hướng dẫn được thiết kế theo triết lý Taste Skill kết hợp phong cách biên tập hiện đại: mỗi màn hình truyền tải trọn vẹn một ý chính, sử dụng trình mô phỏng tương tác trực tiếp thay cho hình minh họa tĩnh, giúp bạn nắm bắt luồng hoạt động từ gốc tới ngọn chỉ trong vài phút đọc lướt.
